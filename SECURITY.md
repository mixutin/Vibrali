# Security Policy

Vibrali is pre-release software. Until the first tagged release, only current `main`
is supported.

Please report vulnerabilities in Vibrali's build scripts, defaults, boot process,
persistence implementation or configuration privately to the repository owner through
GitHub rather than publishing an unpatched issue.

For third-party packaged tools, also report vulnerabilities to the upstream project.

## Workstation defaults

The shipped workstation security model, firewall behavior, privilege defaults and service posture are documented in [docs/SECURITY_BASELINE.md](docs/SECURITY_BASELINE.md).

The project threat model and current limitations are documented in [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).
